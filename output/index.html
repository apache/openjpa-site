Welcome to the Apache OpenJPA project¶

Apache OpenJPA software provides a complete, production-ready implementation of the Jakarta Persistence API (JPA) for building portable, standards-based Java persistence applications. It can be used as a stand-alone Java persistence layer or integrated into any Java EE compliant application server and many lightweight frameworks, such as Tomcat and Spring.

Apache OpenJPA is a Java persistence project at The Apache Software Foundation that can be used as a stand-alone POJO persistence layer or integrated into any Java EE compliant container and many other lightweight frameworks, such as Tomcat and Spring.

Specification support¶

4.2.x releases Current Jakarta Persistence API 3.2
4.1.x releases Jakarta Persistence API 3.1
4.0.x releases Jakarta Persistence API 3.0
3.x releases JSR-338 Java Persistence 2.2 (backward compatible with JPA 2.1, 2.0, 1.0)
2.x releases JSR-317 Java Persistence 2.0 (passes the Sun JPA 2.0 TCK)
1.x releases Java Persistence API 1.0 (JSR-220 EJB 3.0, latest 1.2.3)
