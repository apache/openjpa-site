OpenJPA 4.1.X

Edit on GitHub

The Apache OpenJPA community is currently mainly working on Apache OpenJPA 4.1.x.

This distribution is based on the Jakarta Persistence API 3.1.

Additional information on the OpenJPA project may be found at the project web site.

Changes in OpenJPA 4.1.1¶

Bug ¶

  • [OPENJPA-2925] - Accessing a non-recursive relation of an instance that has been loaded via a recursive relation may produce wrong result
  • [OPENJPA-2936] - Usage of JPA @Index without name prevents creating schema and queries

Changes in OpenJPA 4.1.0¶

Bug ¶

  • [OPENJPA-2898] - Cannot resolve the name 'orm:versionType'
  • [OPENJPA-2928] - Missing orm and persistence xml v3 schemas for offline processing
  • [OPENJPA-2930] - UUID ID Generator Strategy
  • [OPENJPA-2932] - Implement numeric JPA 3.1 JPQL functions and equivalent Criteria API
  • [OPENJPA-2933] - Implement new date JPA 3.1 JPQL functions and equivalent Criteria API

Task ¶

  • [OPENJPA-2934] - Offline XSD schema for JPA 3.1. should be added
