OpenJPA Documentation

Apache OpenJPA provides complete reference documentation covering installation, configuration, mapping, enhancement, and the Jakarta Persistence API. The current documentation is generated from the project source and published as a standalone manual for each release.

Also in this guide¶

  • Entity Enhancement - instrument your persistent classes.
  • Integration Guide - run OpenJPA inside application servers and containers.
