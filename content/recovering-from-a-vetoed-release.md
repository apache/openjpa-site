# Recovering from a vetoed release

This page described the release process of earlier OpenJPA versions and is no longer maintained. It covered what to do when a release vote fails.

The current release process is described in [RELEASING.md](https://github.com/apache/openjpa/blob/master/RELEASING.md#if-the-vote-fails) in the OpenJPA repository.
For downloads and how to verify them, see the [Downloads](downloads.html) page.
