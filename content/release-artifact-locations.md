# Release Artifact Locations

This page described the release process of earlier OpenJPA versions and is no longer maintained. It covered where release artifacts are staged and published.

The current release process is described in [RELEASING.md](https://github.com/apache/openjpa/blob/master/RELEASING.md) in the OpenJPA repository.
For downloads and how to verify them, see the [Downloads](downloads.html) page.
