# Apache Nexus Release Process (1.2.x-2.1.x)

This page described the release process of earlier OpenJPA versions and is no longer maintained. It covered the release process with Nexus.

The current release process is described in [RELEASING.md](https://github.com/apache/openjpa/blob/master/RELEASING.md#setting-up-a-vote) in the OpenJPA repository.
For downloads and how to verify them, see the [Downloads](downloads.html) page.
