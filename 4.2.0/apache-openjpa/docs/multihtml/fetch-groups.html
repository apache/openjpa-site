3.7.4.1.1. Fetch Groups

The org.apache.openjpa.persistence.FetchGroups and org.apache.openjpa.persistence.FetchGroup annotations allow you to define fetch groups in your JPA entities. Fetch Groups discusses OpenJPA’s support for fetch groups in general; see Custom Fetch Groups for how to use these annotations in particular.
