2.13.8.1. Basic Mapping

A basic field mapping stores the field value directly into a database column. The following field metadata types use basic mapping. These types were defined in Field and Property Metadata.

  • Id fields.

  • Version fields.

  • Basic fields.

In fact, you have already seen examples of basic field mappings in this chapter - the mapping of all identity fields in Identity Mapping. As you saw in that section, to write a basic field mapping you use the Column annotation to describe the column the field value is stored in. We discussed the Column annotation in Column. Recall that the name of the column defaults to the field name, and the type of the column defaults to an appropriate type for the field type. These defaults allow you to sometimes omit the annotation altogether.
